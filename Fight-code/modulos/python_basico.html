El lenguaje

¿Qué es Python?

Python es un lenguaje de programación de propósito general, conocido por una sintaxis legible. Se utiliza para automatizar tareas, crear aplicaciones web, analizar datos, desarrollar herramientas y explorar inteligencia artificial.

En Python, la indentación organiza los bloques de código. Las variables se crean al asignarles un valor, y no es necesario declarar previamente su tipo.

nombre = "Alex"
print(f"Hola, {nombre}!")
Este módulo recorre cinco bases: instrucciones y sintaxis, datos, condiciones, colecciones y ciclos, funciones y depuración.
